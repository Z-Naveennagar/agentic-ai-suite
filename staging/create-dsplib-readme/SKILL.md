# Create DSPLib README

Use this skill to create a README file for a DSPLib project created from the create-dsplib-graph skill

## Workflow Steps

1. Create Default README

## Create Default README

* Create the README file with the following sections:
	* Project Description: A brief description of the project and its functionality.
	* Graph Functionality: A detailed explanation of the AI Engine graph, including the DSP Library IPs used and their configuration.
	* Build Instructions: Step-by-step instructions on how to build the project using the generated Makefile.
	* Simulation Instructions: Step-by-step instructions on how to run simulations for the project.
