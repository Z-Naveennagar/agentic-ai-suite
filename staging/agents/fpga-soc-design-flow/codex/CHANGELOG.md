# Changelog

- Package the Codex implementation under a runtime-specific staging path.
- Add deterministic, user-readable assurance gates between agents.
- Record exact inputs, outputs, decisions, checks, side effects, approvals, uncertainty, and artifact hashes.

- Add durable run/campaign status and bounded campaign resource guards.
- Add portable hardware-test plans, typed lab target profiles, and debug-map validation.
- Exclude open-gate context files from finalized receipt discovery.
- Add 50 ordered KV260 evaluation cases alongside two Basys 3 smoke cases.
