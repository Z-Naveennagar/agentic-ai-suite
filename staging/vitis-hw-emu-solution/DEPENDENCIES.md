# Dependencies

---

## Toolchain

Vivado and Vitis **2025.2** are required. Source both settings scripts before running any step:

```bash
source /proj/xbuilds/2025.2_released/installs/lin64/2025.2/Vivado/settings64.sh
source /proj/xbuilds/2025.2_released/installs/lin64/2025.2/Vitis/settings64.sh
```

Switch versions by replacing `2025.2` with `2025.1`, `2024.2`, `2024.1`, etc.

### Bundled Tools

No additional installs required. All tools below are included with Vivado/Vitis:

| Tool | Bundled with | Used for |
|------|-------------|---------|
| `xsim` | Vivado | PL RTL simulation in hw_emu |
| `aarch64-linux-gnu-g++` | Vitis | Cross-compiling host app for ARM |
| `aiecompiler` | Vitis (`aietools/`) | AIE graph compilation (VCK190 only) |
| `emconfigutil` | Vitis | Generating `emconfig.json` |
| `platforminfo` | Vitis | Validating `.xpfm` packages |
| Python 3 (Vitis API) | Vitis | Running `platform_creation.py` |

## Environment Variables

These are **not set by `settings64.sh`** — export them manually before running make:

### ZCU104

```bash
export PLATFORM_REPO_PATHS=/proj/rdi/xbuilds/released/2025.2/2025.2_released/internal_platforms
export COMMON_IMAGE_ZYNQMP=${PLATFORM_REPO_PATHS}/sw/zynqmp/xilinx-zynqmp-common-v2025.2/
export SYSROOT=${COMMON_IMAGE_ZYNQMP}/sysroots/cortexa72-cortexa53-amd-linux
```

### VCK190

```bash
export PLATFORM_REPO_PATHS=/proj/rdi/xbuilds/released/2025.2/2025.2_released/internal_platforms

```

### EDF (VCK190 / VEK280 / VRK160 / VEK385 — `references/edf/`)

The EDF flow uses a **pre-built base platform** plus **pre-built Yocto images** — *not* a PetaLinux `COMMON_IMAGE_*`. These are not set by `settings64.sh`:

```bash
# Pre-built base platform comes from the Vitis install base_platforms (NOT internal_platforms)
export PLATFORM_REPO_PATHS=<Vitis_tools>/base_platforms      # holds vek385_base_reva/, vek280_base/

# Downloaded Yocto EDF artifacts (app SDK + disk-image WIC + QEMU prebuilt)
export YOCTO_ARTIFACTS=<path-to-design>/yocto_artifacts
# export YOCTO_QEMU_ARTIFACTS=<path>                         # optional fallback source

# Sysroot is established by sourcing the EDF app-SDK installer:
source ${YOCTO_ARTIFACTS}/amd-cortexa78-mali-common_meta-edf-app-sdk/sdk.sh -d ./yocto_artifacts/ -y
# SYSROOT then resolves to ${YOCTO_ARTIFACTS}/<edf-app-sdk>/sdk/sysroots/cortexa72-cortexa53-amd-linux/
```

EDF image login is `amd-edf` / `amd-edf`. Per-board: VEK385 (Gen2) uses the **Cortex-A78** set (`amd-cortexa78-mali-common` / `vek385_base_reva`); VCK190, VEK280, and VRK160 (Gen1) use the **Cortex-A72** set (`amd-cortexa72-common` / `vck190_base` / `vek280_base` / `vrk160_base`). See `references/edf/` for the full matrix.

## Common Images

Pre-built Linux stacks provided by AMD — no PetaLinux build required.

### ZCU104 — `COMMON_IMAGE_ZYNQMP`

```
/proj/rdi/xbuilds/released/2025.2/2025.2_released/internal_platforms/sw/zynqmp/xilinx-zynqmp-common-v2025.2/
```

| File | Purpose |
|------|---------|
| `Image` | Linux kernel |
| `rootfs.ext4` | Root filesystem |
| `boot.scr` | U-Boot script |
| `bl31.elf` | ARM Trusted Firmware |
| `u-boot.elf` | U-Boot bootloader |
| `sysroots/cortexa72-cortexa53-amd-linux/` | Cross-compilation sysroot |

> `fsbl.elf` and `pmufw.elf` are auto-generated by the Vitis platform build.

### VCK190 — `COMMON_IMAGE_VERSAL`

```
/proj/rdi/xbuilds/released/2025.2/2025.2_released/internal_platforms/sw/versal/xilinx-versal-common-v2025.2/
```

| File | Purpose |
|------|---------|
| `Image` | Linux kernel |
| `rootfs.ext4` | Root filesystem |
| `boot.scr` | U-Boot script |
| `bl31.elf` | ARM Trusted Firmware |
| `u-boot.elf` | U-Boot bootloader |
| `sysroots/cortexa72-cortexa53-amd-linux/` | Cross-compilation sysroot |

> Versal PLM is embedded in silicon — no PLM, FSBL, or PMUFW artifact needed.

### EDF (VCK190 / VEK280 / VRK160 / VEK385) — `YOCTO_ARTIFACTS`

The EDF flow does **not** use a PetaLinux common image. Instead, download the board's Yocto EDF set from the AMD EDF / Embedded Design Tools downloads page into `${YOCTO_ARTIFACTS}/`:

| Artifact | Example (VEK385 Gen2, Cortex-A78) | Purpose |
|----------|------------------------------------|---------|
| App SDK | `amd-cortexa78-mali-common_meta-edf-app-sdk` | Cross-compile sysroot (`source sdk.sh`) |
| Disk image (WIC) | `amd-cortexa78-mali-common_edf-platform-disk-image` → `*.wic.ufs` / `*.wic.xz` (2025.2: `…_edf-linux-disk-image`) | rootfs for emulation + SD |
| QEMU prebuilt | `amd-cortexa78-mali-common_vek385_qemu_prebuilt` | QEMU boot config + bootloaders |
| OSPI image | board OSPI/QSPI boot image | physical-board boot |

The Gen1 boards use the **Cortex-A72** set (`*.wic.qemu-sd`) with a per-board QEMU prebuilt:

| Board | App SDK | Disk image | QEMU prebuilt |
|-------|---------|-----------|---------------|
| VCK190 | `amd-cortexa72-common_meta-edf-app-sdk` | `amd-cortexa72-common_edf-platform-disk-image` | `amd-cortexa72-common_vck190_qemu_prebuilt` |
| VEK280 | `amd-cortexa72-common_meta-edf-app-sdk` | `amd-cortexa72-common_edf-platform-disk-image` | `amd-cortexa72-common_vek280_qemu_prebuilt` |
| VRK160 | `amd-cortexa72-common_meta-edf-app-sdk` | `amd-cortexa72-common_edf-platform-disk-image` | `amd-cortexa72-common_vrk160_qemu_prebuilt` |

The base platform `.xpfm` (`vck190_base` / `vek280_base` / `vrk160_base` / `vek385_base_reva`) comes from `PLATFORM_REPO_PATHS` (Vitis install `base_platforms`), not from these downloads.

## Simulator

Default simulator is **XSIM** (bundled with Vivado, no license required). Xcelium and Questa are also supported with the appropriate license.
