# Create Kernel

Use this skill to create all files required for an AI Engine kernel

## Workflow Steps

1. Create kernel header file using `create-kernel-hpp` skills
2. Create kernel source file using `create-kernel-cpp` skills
3. Create kernel config file using `create-kernel-cfg` skills
4. Create kernel constraints file using `create-kernel-aiecst` skills
5. Create kernel graph file using `create-kernel-graph` skills
6. Create kernel app file using `create-kernel-app` skills
7. Create kernel Makefile using `create-kernel-Makefile` skills
