# AMD Embedded Agentic AI Suite — Installation Guide

Set up the AMD Embedded Agentic AI Suite in your preferred development environment. This guide covers installation and configuration for all tools in the suite:

- **Agent Skills** — install Vivado and HLS methodology skills with `npx skills add`
- **Vivado MCP Server** — MCP server for AI-driven FPGA design automation with Vivado (VS Code, Cursor, Claude Code, Copilot CLI, Codex CLI)
- **ChipScope MCP Server** — AI-powered hardware debug for AMD Versal devices (VS Code, Cursor, Claude Code)
- **Vitis HLS AI Assistant** — agent skills for high-level synthesis workflows (no MCP server required)

Each MCP server section covers prerequisites, download, and per-client configuration.
