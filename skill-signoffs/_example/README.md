# Skill signoff example

This directory is a committed reference for the versioned evidence reviewers inspect before promoting a skill from `staging/` to production. Normal packages generated by `skills-test run` are written beside `_example/` and remain ignored by Git.

The IP-configurator package is based on real run `437ff984` and demonstrates:

- a snapshot of the exact skill content tested;
- a self-contained interactive HTML report;
- repeated execution across multiple clients and models;
- lifecycle conclusions and the evidence used to reach them;
- cost and token-consumption reporting.

This example is documentation, **not an approval to promote the included skill**. It intentionally contains mixed outcomes so reviewers can compare a `KEEP` conclusion with a `WATCH` conclusion.

## Layout

```text
ip-configurator_summary/
├── ip-configurator/       # exact tested skill snapshot
└── report/
    ├── README.md          # concise run and lifecycle summary
    └── report.html        # self-contained interactive evidence
```

Open `ip-configurator_summary/report/report.html` in a browser. Use its filters, expandable case rows, repetition tabs, column controls, and lifecycle evidence disclosures to inspect the run.
